# TeamSpeak Online Bot

Небольшой Telegram-бот на Go показывает пользователей TeamSpeak 6 по каналам. На `/start` и `/online` бот отвечает без звука, удаляет старую клавиатуру и показывает общее количество людей, занятые каналы, количество и ники в каждом канале. Служебные подключения ServerQuery не учитываются. Бот не рассылает сообщения автоматически.

## Настройка

Нужны Telegram-токен от BotFather и API-ключ TeamSpeak WebQuery с правом чтения списка каналов и пользователей. WebQuery должен быть включён и доступен из контейнера. По умолчанию используется адрес `http://127.0.0.1:10080/1`: это порт WebQuery на самом сервере и виртуальный сервер с ID `1`. Если он выключен, один только бот его не включит. Используйте HTTPS для WebQuery, если он находится на другом сервере; не открывайте WebQuery в интернет без необходимости.

На сервере настройте файл с секретами, например `/root/ts6-online-bot.env` (ключи не вставляйте в чат и не загружайте в Git):

```env
TS6_BOT_TOKEN=токен_телеграм_бота
TS6_WEBQUERY_URL=http://127.0.0.1:10080/1
TS6_WEBQUERY_KEY=ключ_webquery
TS6_ALLOWED_CHAT_IDS=
```

Установите `chmod 600 /root/ts6-online-bot.env`. Пустой `TS6_ALLOWED_CHAT_IDS` означает, что любой пользователь, знающий бота, может запросить список участников. Чтобы ограничить доступ, перечислите числовые ID чатов через запятую, например `TS6_ALLOWED_CHAT_IDS=123456789,-1001234567890`. В группе разрешение по ID группы распространяется на всех её участников.

## Установка на Linux с Docker

```bash
git clone https://github.com/ВАШ_АККАУНТ/ts-online-vpn-bot.git
cd ts-online-vpn-bot
docker build -t ts-online-vpn-bot:local .
docker run --rm --network host --env-file /root/ts6-online-bot.env ts-online-vpn-bot:local --check
```

Проверка обращается к Telegram и TeamSpeak, в том числе к списку каналов. Если она прошла, а контейнера с именем `ts-online-bot` ещё нет:

```bash
docker run -d --name ts-online-bot --restart unless-stopped \
  --network host --env-file /root/ts6-online-bot.env ts-online-vpn-bot:local
docker logs --tail 30 ts-online-bot
```

`--network host` предназначен для Docker на Linux и позволяет обратиться к WebQuery на `127.0.0.1`. Порт 10080 должен быть опубликован на localhost сервера, если TeamSpeak находится в отдельном контейнере bridge. Если у Telegram-бота включён webhook, его нельзя одновременно использовать с long polling; `--check` это обнаружит и не будет автоматически менять webhook.

Если уже работает старый бот с тем же Telegram-токеном, перед запуском нового остановите старый контейнер: два процесса одновременно получать команды не должны. Старый контейнер и env-файл можно сохранить для отката.

## Локальная разработка

Откройте папку проекта в GoLand; требуется Go 1.24 или новее. Переменные окружения задаются в конфигурации запуска GoLand или через окружение процесса; `.env` автоматически не читается.

```bash
go test ./...
go run .
```

Список каналов и пользователей запрашивается последовательно, поэтому при переходе участника между каналами во время запроса возможна кратковременная неточность.
